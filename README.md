# Billete para una nueva vida

Site statique de préparation au CAFEP-CAPES externe d'espagnol, conçu pour Jennifer.

## Contenu

- double parcours session 2027 : bac+3 et bac+5 ;
- programme officiel et formats d'épreuves ;
- littérature, civilisation, traduction, faits de langue et didactique ;
- préparation de la leçon et de l'entretien ;
- synthèse du rapport de jury 2025 ;
- 145 flashcards français–espagnol avec synthèse vocale du navigateur ;
- diagnostic de 30 questions, chronomètres et sujets d'entraînement ;
- progression locale exportable/importable ;
- accessibilité et fonctionnement hors connexion.

## Mise en ligne sur GitHub Pages

1. Créer un nouveau dépôt public, par exemple `billete-para-una-nueva-vida`.
2. Décompresser le ZIP et déposer **le contenu du dossier**, en veillant à placer `index.html` à la racine du dépôt.
3. Dans GitHub : **Settings → Pages**.
4. Dans **Build and deployment**, choisir **Deploy from a branch**.
5. Sélectionner la branche `main` et le dossier `/ (root)`, puis enregistrer.
6. Attendre le lien fourni par GitHub Pages.

## Vie privée

Le site n'utilise aucun serveur, compte, cookie publicitaire ou outil d'analyse. La progression reste dans `localStorage` et peut être exportée en JSON.
